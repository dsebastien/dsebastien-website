# Search engines may index every note

Two reviews advised to set thin note types (media, quotes, people: about 69 percent of the notes) to `noindex`, to protect the quality signals of the host. The author decided that everything is indexed.

Consequence: no `noindex` rule by note type. A per-note override stays possible. Because thin pages are indexed, their quality matters: generated descriptions from properties, the author's own text where it exists, and list pages that group them.
