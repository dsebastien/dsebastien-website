# The publishing tool is built before the switch, with no bridge through Obsidian Publish

A bridge was proposed: keep the Obsidian Publish panel as the place to select and review, and let the new site read the published list. It would have taken the publishing tool off the critical path of the switch. The author rejected it: no dependence on Obsidian Publish in any form.

Consequence: the first version of the own tool (queue, select, publish, unpublish, takedown) is a condition of the switch gate. It is kept as small as possible, and everything else in the tool comes after the switch.
