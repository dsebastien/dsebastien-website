# Separate hosts stay, and this project covers the notes website only

The first draft of the spec merged the notes site, the main site and the store into one codebase and, later, one host name. The author decided to keep the existing subdomains (notes, store, stats) and to leave the main site and the store untouched. This project replaces Obsidian Publish for the notes website and nothing else. The codebase can host other sections later, but no decision here may depend on that.
