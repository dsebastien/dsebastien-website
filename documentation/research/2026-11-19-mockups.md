# Mockups of the home page and of the note page (issue 24, PROTO-06)

Date: 2026-11-19. Branch: `prototype/mockups` (commit `dd51c28`). The pages are at `/-/mockups/` of the dev server of the site on that branch (`bun run dev`). All content of the mockups is invented.

## What was built

- The token contract (`apps/site/src/styles/tokens.css`): Tailwind 4 theme variables for colors, fonts, radii, shadows and motion. The default palette, fonts, radii and shadows of Tailwind are switched off. Components use the utilities of the tokens only.
- The theme `knowii` (`apps/site/src/styles/themes/knowii.css`): the Knowii web palette of the store website in the dark mode, and the light mode of the store, completed. Dark is the default. A script in the head sets the mode before the first paint: a stored choice, else the mode of the system, else dark.
- Noto Sans, served by the site (`@fontsource-variable/noto-sans`, split by Unicode range).
- Variant A, "Reading room": a quiet bar, one centered reading column, the outline on the right, the author line under the title, the cite block and the share row after the text.
- Variant B, "Atlas": a bar on the surface with the search in the middle, a title band on the note page, the outline in a left rail, the author line, the cite block and the share row in a right rail on wide screens (after the text on small screens), denser lists on the home page and a filled newsletter band.
- Each variant has a home page, a concept note page and a book note page (with the key facts box of a media note), in the decided order of NAV-02 and of section 11.2.3 of the spec.

## Contrast (WCAG 2.2)

Measured on the background and on the surface of each mode:

| Pair                 | Dark       | Light       |
| -------------------- | ---------- | ----------- |
| Text (`primary`)     | 10.5 / 9.1 | 15.9 / 17.1 |
| Muted text (`muted`) | 6.1 / 5.3  | 6.1 / 6.6   |
| Link (`link`)        | 10.5 / 9.1 | 5.6 / 6.0   |
| Focus ring (`focus`) | 10.5 / 9.1 | 5.6 / 6.0   |

In the dark mode a link is the text color with an underline in the signature pink (`#ff1493` is 2.9:1 on the background, so it is decoration only). In the light mode a link is `#c20066`.

## Choice of the author

1. Variant B, "Atlas". He asked for more visual impact later, for example a lightly animated background of moving nodes: GitHub issue 81, to prototype after the design base.
2. The site name: "Sébastien’s Notes" (OPEN-06, D54).
3. The display title rule of IDX-03 is confirmed (OPEN-08): the `title` property when it is set, not empty and not the file name; else the first level-one heading; else the file name; the prefix and the suffix of the note type removed.
